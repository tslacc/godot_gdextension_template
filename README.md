# godot_gdextension_template
A template for the C-based GDExtension for the Godot game engine.
Based off the official tutorial: https://docs.godotengine.org/en/stable/engine_details/engine_api/gdextension/index.html#the-gdextension-system

Build by running make: this builds and outputs the final shared library to /tmp/build or wherever tmpdir is.
